# 学習BASE を直す手順と記録

設計：`-` リポジトリ `principles/learning-app-foundation.md` §15。実装：`gas/Telemetry.gs`（失敗と速さ）・`gas/Tuning.gs`（閾値を見直す）・`gas/Export.gs`（気づきと書き出し）。

## 考え方（決定 2026-11-10）

- 使い勝手の問題を **見つける・原因を突き止める** のは、実際に使う場の観察（所有者・担任）。Claude は **直し方を決める・実装する・検査する**。
- だから改善の入力の主役は **観察の報告＋画面写真**。自動で集めるのは、観察では見えないもの（失敗・実機の速さ）と、直した時に効いたかを比べる数（始めるまで）だけ。
- Claude に渡すのは使い勝手・機能性だけ。児童の学習状態（個人も集団も）は渡さない。閾値は学校の中で直す。

| 何を直すか | どこで | 材料 |
|---|---|---|
| 画面・機能・速さ・失敗 | Claude（PR → マージで反映） | 観察の報告・撮影用の画面写真・「失敗と速さ」の書き出し・先生の気づき |
| 今週の3件の閾値 | 学校の中（所有者が「閾値を見直す」で値を変える。ハブの `rules`、翌晩から効く） | 候補の数・1つずつ変えたら・分布・出た件数（画面の中だけ） |

## 観察の報告（Claude に渡す書式）

```
いつ：11/12 2時間目
誰が：3年の児童 2人（1人は 4GB 機）／先生（自分・他の先生）
どの画面で：学習BASE のホーム → 算数
何をしようとして：九九を始めようとして
何が起きたか：「いまの学習」に気づかず、教科の算数から探した。算数の中でタイルを2回押し間違えた
どれくらい困ったか：先生が声をかけるまで1分ほど止まった／自分で解決した／毎回起きる
写真：撮影用で撮った画面（あれば）
```

- 1件ずつでよい。「毎回起きる」「何人も」は重く扱う。
- 授業中に2〜3人の様子を5分見るだけで、多くの問題が見つかる（Nielsen & Landauer 1993。人数と見つかる割合には幅がある）。児童と先生は別に見る。

## 自動で集めるもの（失敗と速さ）

所有者：先生の画面の一番下「失敗と速さを見る・書き出す」→「コピーする」→ Claude に貼る。月曜のメールに、所有者へ直近7日の失敗の件数が1行出る（失敗が無ければ出ない）。

| 表 | 中身 | 読み方（Claude 向け） |
|---|---|---|
| 開いた回数 | 役割ごと | 下の表の分母 |
| 1. 失敗 | err＝サーバー（どこで:エラー文）／js＝画面の JavaScript／client＝読み込めない。メール・ID・長い数は伏せる | 出たら必ず直す。同じ失敗が続くなら優先 |
| 2. 速さ | srv＝サーバーの処理／rt＝表示までの往復（4GB以下／8GB 別） | 4GB 機で 4秒以上が多ければ、画面かサーバーの処理を軽くする |
| 3. 始めるまで | 児童がホームを開いてから最初のページを開くまで（学年:経路:時間）、教科の行き止まり | 直した前後で比べる。経路の偏り（いまの学習を使っていない等）は観察で理由を確かめる |
| 4. 設定 | かくしたページ・いまの学習・閾値を変えたか | 使われていない操作は見つけにくさを疑う |
| 5. 気づき | 名前は記号に置き換え済み | 同じ指摘が2回出たら直す |

- 「目で確かめる」が出たら読む（気づきに名前があった等）。学習のようすが書かれた気づきは、ハブの `feedback` で書き直してから書き出し直す。
- 画面写真は、先生の帯の「撮影用」を押してから撮る（配置はそのまま、名前と数字が見本。ページは開かず、押しても記録しない）。
- 算数TA など、アプリ自身の画面の失敗はまだ集めていない（学習BASE のホームと、アプリのサーバーの失敗だけ）。

## 閾値を直す（学校の中で）

1. 所有者：先生の画面の一番下「閾値を見直す（学校の中だけ）」。
2. 値を変えて「この値で数える」→「入れた値なら」の行で、今週の候補の数を比べる。「1つずつ変えたら」と散らばりの表、今週の3件と先生の反応の表も見る。
3. 「保存する」（今夜から）か「保存して今すぐ計算し直す」。「すべて初期値にもどす」で戻せる。
4. 目安（初期値。根拠なし）：学級あたりの候補が「学級ごとに出す数」を大きく越える規則は、下位が出ないので厳しくする。
   「見た」ばかりで「判断が変わった」が少ない種類は、当たっても手を変えるほどではない（厳しく）。「押されていない」が多い時は、先生が開いているか（開いた回数）を先に見る。
