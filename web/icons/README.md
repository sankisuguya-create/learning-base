# タブアイコン

学習BASE と教科のアプリのタブアイコン（ファビコン）。正本は SVG。学校に配る時は PNG にして、GAS の `setFaviconUrl` で付ける（URL の末尾が `.png` でないと受け付けないため。組み込みは別の PR）。
一覧は `gallery.html`（ブラウザで開く）。

## 採用（2026-11）

| ファイル | 使う所 | 形 |
|---|---|---|
| `adopted/base.svg` | 学習BASE のホーム | アナログテレビ（銀・つまみ付き）。暗い画面の中央に3色の帯、その上に白い B（BIZ UDPゴシック。少し左寄せ。B の穴から帯が透ける）。`base-b/` は検討した案 |
| `adopted/base-app.svg` | 学習BASE の画面の中（右下に固定するテレビ） | `base.svg` の帯を、教科のアイコンと同じく少しぼかして光らせ、上下の端に極細ライン（帯の赤→水色→紫をわずかに明るくした色。少しぼかし、帯との境目をやわらげる）を引いたもの。タブには `base.svg` を使う |
| `adopted/tamath.svg` | 算数タイムアタック | ストップウォッチ。濃紺の地に、円周の点（素因数分解TA の色：シアン→青→藍） |
| `adopted/kanzi.svg` | 漢字の森 | 木（黄緑→緑→深緑のグラデーション） |

- 3つは外形（四角いテレビ・丸・木）で見分ける。色を取り去っても区別できる（color-coding スキルの「色は二重符号化」）。
- 3色（赤・水色・紫）は「学習BASE に入っている教科・アプリ」の印として、学習BASE のアイコンで共通に使う。

## 検討中

- `base-b/`：画面に「B」が入る学習BASE の3パターン（b1＝採用／b2 3色のグラデーションの B／b3 帯の上に白い B）
- `subjects/`：教科ページの左上に大きく置く用。画面に教科名（2字まで。外国語は「英語」）。黒い画面の中央に太い帯：school-timetable の教科色の色相で、淡い色→鮮やかな色→少し深い色のグラデーション。帯の上下の端に極細ライン：帯と同じ向きで、左に淡い色・右に濃い色（その教科の色相の前後。例：算数＝淡いシアン→濃い紫。国語・体育・総合は帯と同じ色）。ラインと帯は少しぼかした光を重ね、ネオンのように光らせる。前の1字の版は `drafts/subjects-v1/`
  ファイル名は `catalog/pages.json` の教科の id。
  **注意**：GAS のタブアイコンはページを返す時にだけ決まる。学習BASE のホームの中で教科を切り替えても、タブアイコンは変えられない（ページの中の表示には使える）。

## 検討した案（drafts/）

採用しなかった案も残す。一覧は `gallery.html`。接頭辞と中身：

| 接頭辞 | 中身 |
|---|---|
| `1-flat-` | 最初の単色案（家・ストップウォッチ＋・木） |
| `g-`・`h-` | グラデーション（明るさだけ／色相もずらす。`h-kanzi` が採用の元） |
| `m-`・`n-`・`r-` | 無機質・数理的な案、算数 A・B、学習BASE の菱形・扇（暖色／全系統の色） |
| `f-`・`k-`・`v-`・`v2-`・`x-` | フォルダとカード・ファイルの案 |
| `y-` | 開いたフォルダの絵文字3種（Noto・Fluent・Twemoji）に3色のファイルを入れた案 |
| `z0`〜`z5` | Noto 黄色に「基地」（旗・家の形・地図のピン・ホームベース・テント） |
| `w-` | station・basement（乗換駅・ハブ駅・駅名標・地下への階段・地下の3階・地下鉄の入口） |
| `tv-` | アナログテレビ（a クリーム・b 木目・c 銀＝採用の元・d 黄） |

## 使っている素材とライセンス

- `drafts/y-noto-*`・`drafts/z*`：Noto Emoji（Google、Apache-2.0）の「開いたフォルダ」を改変
- `drafts/y-fluent-emoji-flat-*`：Fluent Emoji（Microsoft、MIT）の「開いたフォルダ」を改変
- `drafts/y-twemoji-*`：Twemoji（Twitter、CC BY 4.0。https://creativecommons.org/licenses/by/4.0/ ）の「開いたフォルダ」を改変
- `base-b/`・`subjects/` の文字：BIZ UDPゴシック Bold（SIL Open Font License 1.1）の字形を図形にしたもの
- それ以外は、このリポジトリで描いたもの
